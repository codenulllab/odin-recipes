# Odin Recipes

This is a simple recipe website built with HTML. It features recipes referenced from [allrecipes.com](https://www.allrecipes.com). This website is made for [The Odin Project](https://www.theodinproject.com)'s assigntment.

By completing this project, I am understand about HTML fundamental, and it is not difficult to learn. Beside that i have also learned other things such as what is git, github, how to clone repository to local, and how to commit, etc. It's a good start!
